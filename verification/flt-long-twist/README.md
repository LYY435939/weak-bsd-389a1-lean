# External FLT adapter

`ExactWitness.lean` and `ExternalDataBridge.lean` connect the fixed upstream FLT modularity results to the 389.a1 proof. They use `anthropics/fermats-last-theorem` commit `6e837e75355538c7f80bab5b956861e86c4eacc2` and Lean 4.33.1. The upstream license and notice are included. See `../flt-389-compat/README.md` for the checked compatibility patch and verification limits. The upstream FLT library and its caches are not included.
